# 何浩冉学习委员竞选网站

这是一个无需后端、无需安装依赖的静态网站。

## 本地查看

直接双击 `index.html` 即可打开。

## 发布到 GitHub Pages

1. 登录 GitHub，新建一个公开仓库，例如 `learning-committee-site`。
2. 把本文件夹中的 `index.html`、`assets` 文件夹、`.nojekyll` 和本说明文件上传到仓库根目录。
3. 打开仓库的 `Settings`。
4. 进入 `Pages`。
5. 在发布来源中选择 `Deploy from a branch`。
6. 分支选择 `main`，目录选择 `/ (root)`，点击保存。
7. 等待 GitHub Pages 完成部署，页面会生成一个公开网址。

上传时请保持 `index.html` 与 `assets` 文件夹处于同一层级，否则图片无法显示。

## 文件说明

- `index.html`：网站页面、样式和交互。
- `assets`：网站实际使用的背景、活动照片和透明人物素材。
- `.nojekyll`：避免静态资源被 GitHub Pages 的默认处理影响。

本分享版不包含未被网站使用的个人证件照文件。
