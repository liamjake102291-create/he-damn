02 / 我为什么来

我对学习委员的理解，
不是“学习好就能当”。

学习委员既要传递信息，也要连接同学；既要完成老师交代的事情，也要让大家在需要时找得到人、问得到问题。

学习，不只是一张成绩单

我比较喜欢学习，但我理解的学习不是单纯完成考试任务，而是对真正感兴趣的东西持续投入，努力让自己在不同方面得到提升。最近我也在学习 ChatGPT、Python、Excel 等工具。

班级，是一起变好的地方

军训这段时间让我发现，我们班同学都很优秀、很聪明，也有自己的想法。我希望以后能和大家一起学习、互相分享，而不是让“不会”变成不好意思开口。

不是一个人偷偷卷，而是让班级学习资料“有回应”、信息传递“不卡顿”、遇到问题“有人接”。
03 / 如果我当选

我会把职责，
落实成几件具体的事。

不画大饼，先从每一次通知、每一份资料、每一个同学的反馈做起。

A / 及时传递

老师交代的事情，及时完成

认真做好学习相关任务的信息整理和传达，重要事项尽量做到清楚、准确、有记录。

B / 资源共享

把有用的资料，整理给大家

配合课程进度整理资料、工具和复习提醒，让大家少一点信息差，多一点可执行的参考。

C / 反馈闭环

同学有需要，我会积极回应

遇到自己不会的问题，我会先认真听，再去查资料或向优秀同学学习，尽量把问题跟进到底。

04 / 我的优势

我最想带来的，
是持续学习的劲头。

班级里有很多优秀同学，学习成绩不是我唯一能拿出来说的优势。但我愿意从自己的长处出发，也愿意承认不足、接受建议、持续改进。

“指出我的不当之处，我会听；发现自己做得不够，我会改。”

自主学习和迁移能力
